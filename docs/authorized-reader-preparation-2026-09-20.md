# 授权读取测试准备与能力边界（2026-09-20）

## 当前结论与状态

用户当前决定：**“没有专用账号，先把测试准备好。”** 本轮只准备隔离测试与验收条件，不提交官方应用，不接受新平台条款，不注册或共享账号，不进行真实登录、模型调用或新增云端部署。

官方授权读取自己的作品，不等于可以读取任意作者的作品。专用浏览器账号能够访问一个页面，也不等于获得平台的官方数据接口授权。两条路径必须分开验证、分开报告，不能互相替代。

代码准备范围包括 `sessionLease` 隔离会话准备，以及 `authorized-acceptance.mjs` 的内部内存接口和仅 `--preflight` CLI。**默认服务仍保持匿名；没有登录采集或扫码 UI，没有生产启用。** 这些准备本身不证明任何授权链接已经读取成功。已实际执行的离线验证：

- `sessionLease`：12 组通过，覆盖分平台、专用账号/用途约束、字段与域名、数据隔离、到期、撤销和大小上限。
- 浏览器读取器：39 组通过，含 7 组新增的会话注入、过期/撤销、中途及清理阶段失效、门禁与身份检查。默认匿名路径的原回归保持通过。
- `authorized-acceptance.mjs`：8 组通过，覆盖离线预检、原 20 样本单次调用、脱敏、撤销/取消、验证码停止、首项/末项抛错的记录完整性。
- 签名服务器原有 10 组通过；读取模块合计 **69/69**。另外原链接离线回归 56/56、V2 回归 31/31、TypeScript 检查通过。没有以 Mock 的 20/20 作为真实链接通过率。
- 本轮真实登录、授权账号真实读取：未执行。
- 本轮模型调用、新增云端部署：未执行。

### 已实现的实验约束

会话只保存在进程内存，不读写登录态文件、不从环境变量接收 Cookie、不读取个人 profile。默认 15 分钟、上限 30 分钟；若任一持久 Cookie 更早过期，则保守提前结束整个会话，不丢弃过期 Cookie 后偷偷转为匿名。每个平台使用独立数据，只接受对应平台域名的 Cookie 和默认 HTTPS origin；不接受跨平台、分区 Cookie 或未支持的扩展字段。`ready` 仅表示实验数据有效，**不是已向平台确认登录成功**。

读取器在新建上下文、发请求、读取 DOM、输出正文和收尾阶段检查会话；50 ms 定时检查负责取消卡住的导航，随后执行已有的有限时清理。授权实验不走匿名 HTTP 兜底，不刷新或回写登录态，不增加抓取权限；原验证码/身份/私网与媒体限制保留。

运行器固定使用 `candidates-20260920.json`，不允许传入新的样本集或公网 endpoint；每条只调用一次，间隔不少于 10.5 秒。登录/验证码/拒绝访问/限流时终止实验，后续项列为未运行；中途抛错的当前项记为“已尝试失败”。失败不会算通过。每轮生成新目录与不可覆盖的检查点，只记录脱敏 URL、ID、长度、哈希、原因和耗时，不保存正文、标题、账号、Cookie 或原始异常。`sessionsBeforeCleanup` 明确是清理前状态；无论成功或异常，退出时撤销租约并关闭读取器。

真实运行函数仅供未来的可信私有登录控制程序在非 root Linux 环境中调用；不会通过 HTTP、默认 `direct-server` 或 systemd 常驻服务启用。CLI 当前只提供：

```sh
node ops/cloud-reader/authorized-acceptance.mjs --preflight
```

已验证其返回 `prepared_not_live_verified`、固定 20 条、零网络/模型请求，以及账号、私有登录流程和平台授权未就绪的明确状态。此命令不会启动浏览器、扫码登录或检测真实链接。旧云端发布包与线上配置保持不变；上一轮真实云端结果仍为 6/20。

## 已核实的官方接口边界

### 抖音

旧版 `GET /video/list/`（`video.list`）的用途是查询授权账号的视频列表；`POST /video/data/`（`video.data`）查询用户特定视频的数据。两者都要求应用权限和用户授权，不是匿名的任意链接读取服务。文档响应含发布文案字段 `title`、作品 ID、分享页、封面、时间和统计信息；未提供视频逐字稿、ASR 结果或可下载的视频源文件，不能把 `share_url` 当成视频下载地址。[视频列表文档](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/search-video/account-video-list)、[特定视频数据文档](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/search-video/video-data/)

当前小程序 `POST /api/apps/v1/video/query/`（`ma.video.bind`）更明确限定为 `access_token` 对应用户上传的视频，并要求企业开发者、申请能力和小程序内用户授权。这是小程序能力，不能直接等同于现有独立 H5 的可用接口。[当前小程序视频查询文档](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/server/basic-abilities/video-id-convert/user-video-data/video-data)

不能照旧教程直接假定申请成功：数据经营能力已升级，官方公告使用 `video.list.bind`／`video.data.bind`，且已移除部分旧字段。本轮未进入控制台，**尚未确认新应用当前可申请的具体 scope、配额及 BeautyProof 场景是否获准**。官方登录文档还要求经营数据能力在 PC 端完成授权。[字段调整公告](https://developer.open-douyin.com/forum/bulletin/post/6736c38048f043667b75f70a)、[登录与授权 FAQ](https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/sdk/mobile-app/permission/overall-permission)

网站路线还有主体和官网门槛：开发者需完成入驻、应用审核；当前入驻文档未将网站应用列入个人主体支持范围。网站商用上线要求官网 ICP 备案且主体匹配或有总分公司关系，不能默认现有 `chatgpt.site` 地址满足条件。[入驻要求](https://developer.open-douyin.com/docs/resource/zh-CN/developer/join/join-into-developer-platform)、[网站上线要求](https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/app-mgmt/pub-app)

OAuth 需预先配置 HTTPS 完整回调地址，校验 `state` 和实际授予的 `scopes`；密钥与 token 只应由后端保管。用户授权可撤销、token 会过期，需要刷新或重新授权，不能视为永久通行证。[网站 OAuth 文档](https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/sdk/web-app/web/permission)

### 小红书

官方账号授权 scope 文档当前将 `basic_info` 标为开放，将 `read_notes` 标为规划中。因此，当前不能把账号登录或基础信息授权当成已开放的笔记正文读取能力，也不能承诺它能支持任意作者的笔记。分享／发布 SDK 的方向是向平台分享或发布内容，不能作为已经具备读取接口的依据。[小红书官方授权 scope](https://openaccount.xiaohongshu.com/docs/scope)

上述文档状态属于本次核查时点；后续若开放状态变化，应重新核实，而不是据此绕开平台限制。

## 账号准备后才能开展的验证

1. **先确定路径与授权。** 若走官方 API，先由用户确认合格主体、应用场景、平台批准范围和内容使用授权；未获批则保持不可用。若走专用浏览器访问测试，先确认账号归属、允许的用途和平台规则；这只是普通页面访问测试，不标记为官方数据授权，也不开放给公众共享账号。
2. **先完成私有云端登录条件，再开始读取。** 由用户在受访问控制的私有云端环境中自行完成必要登录、扫码和授权确认。用户不需要把密码交给助手；不搬运本地个人 profile／cookies 到云端，不复用现有个人登录会话。当前尚无登录 UI，这一步需要单独明确实施和授权，不能被预检代替。
3. **确认隔离与退出机制。** 会话限专用测试账号和当前受控验收，短时有效、单任务使用、可撤销；凭据不进入源码、Git、日志或验收报告。不得把账号会话接到匿名公众请求或默认生产服务。
4. **先离线预检，再用固定原 20 条样本。** 保留原样本编号与目标作品身份，不用替换难样本、追加重试来凑成功率。正式读取前再次确认执行范围与预算；不调用模型，不自动下载媒体。验证官方 API 时，非授权作者样本应记录为授权范围不支持，不借专用账号强行扩大查询范围。
5. **遇门禁按事实记失败。** CAPTCHA、登录要求、访问限制、限流、App 引导、作品不可用或离开原作品页面，都保留实际失败原因；不绕验证码、不逆向签名、不轮换代理、不无限重试。若出现账号风险或需要新的授权，停止并交回用户处理。
6. **严格验收原作品正文。** 成功须确认作品 ID 与原输入一致，文案确实来自该作品；推荐页、分享标题、封面、空正文或另一作品不算成功。发布文案与视频内口述内容分开标注，不把文案读取写成已经取得完整视频内容。

## 报告必须分开的结果

- **离线准备通过：** 说明代码与边界断言通过，不说明平台真实可读。
- **非公开授权账号端到端通过：** 说明特定账号、环境和固定样本的实测结果，同时列明授权范围、有效期和失败项；不外推为所有账号、所有链接可用。
- **公开生产服务通过：** 还需单独核实前台到云端链路、平台许可、用户授权隔离、数据保留与运行限制。本轮没有完成或启用这一阶段。

现阶段交付是测试准备，不是新增可用的公共读取能力。官方授权账号自己的作品通道可以独立评估；“任意访客粘贴任意作者链接”仍没有从上述官方接口得到支持依据。
