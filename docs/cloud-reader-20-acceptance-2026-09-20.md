1. 短链末跳路径 `/discovery/item/<id>` 与规范路径 `/explore/<id>` 不同，被错误当作无效结果，且错误分类成 network_error。修复后按平台与作品 ID 校验末跳；首跳仍严格对应输入；错 ID 返回 identity_mismatch，结构问题返回 parse_failed。
