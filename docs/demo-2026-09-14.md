# 三分钟演示脚本

1. 打开首页。先确认没有“暂停/额度用完”提示；如有，解释限制，不靠刷新反复调用。我们分析推荐内容，不鉴定瓶中实物。
2. 粘贴一个能读取的公开作品链接，展示“读取了哪些内容”，不要把拿到标题说成完整视频已分析。
3. 展示报告中的具体引文、理由与证据链接。指出通用资料不能证明某款产品有效，历史科普不是实时备案查询。
4. 展示辟谣例子或普通保湿例子。先填写再检测，不演示预置假答案。每次新生成会消耗共享额度。
5. 展示一条读取失败的链接，保留链接，补充用户有权使用的原文或截图；报告注明补充内容未经确认与链接完全一致。
6. 展开成分及分析范围；点击打印时所有证据展开。报告不是监管认定、医学诊断或实物鉴定证书。

## 交付前人工检查

- 两名成员复核至少12条真实内容的原文、来源和预期判断；目前人工构造校准不可替代此项。
- 5位目标用户测试是否能完成提交、理解“证据不足”不是“假货”、找到依据。
- 手机实际截图、真实截图OCR、真实视频范围、打印PDF检查。
- 队长确认官方提交格式、素材授权与早鸟通知；拟10月5日内部冻结，10月7日截止以主办方确认为准。

以上为工作计划和演示指引，不表示已完成访谈、所有媒体测试或已报名提交。
