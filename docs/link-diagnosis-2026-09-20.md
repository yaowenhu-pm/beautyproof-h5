# 2026-09-20 链接读取排查与修复

范围：小红书、抖音公开作品读取；不修改模型、密钥、预算或资料库。全部测试不调用付费模型。

## 已核实的原因

1. 用户提供的 `6a8b8c2200000000350277ca` 小红书作品，带原始签名参数请求仍返回“当前内容仅支持在小红书 APP 内查看”。不是缺少 API 密钥或模型故障，不能据此判断作品被删除或为假。
2. 抖音既有样本 `7677397234564041990` 返回 HTTP 200 的 JavaScript 校验页，没有可供解析的作品数据；HTTP 200 不等于取得正文。
3. 原程序把 App 专用、验证码、未找到状态数据统称为“平台未开放”，且正常响应中的读取失败也缓存 5 分钟。
4. 原程序的 canonical、推荐 meta、缺 ID 状态对象可能造成身份串用；合法正文提到“记录美好生活”会被误判成平台门禁；字符串中的 undefined 被兼容逻辑改写。
5. 抖音只读取一种状态和首个视频 URL，忽略图文图片和可用 CDN 备用 URL；签名分享文本中的 Markdown/HTML 转义可能破坏查询参数。

## 已实现

- 分享文本只选择一条唯一作品/短链，排除首页干扰，保留签名参数，规范 Markdown/HTML 转义。多个不同作品要求用户分开提交。
- 原始作品 ID、跳转 ID、canonical 与 OG URL 一致性检查；状态内不同 ID 或无可靠身份时停止，不改读推荐作品。
- XHS 桌面 detail map、H5 状态；抖音 Router、Render、JSON hydration 数据兼容；只解析 JSON，不执行站点脚本。
- 视频、抖音图文、XHS 图片/视频提取；共享下载域名规则，优先选择下载接口支持的备用 CDN 地址。
- 返回版本、明确原因码、上游 HTTP 状态、去查询参数的跳转路径和时长。日志不含签名、Cookie、正文或媒体链接。
- 成功缓存 5 分钟，失败仅 10 秒，同链接并发合并；18 秒总时限、2 MB HTML 上限、逐跳域名校验维持。
- 界面区分格式识别/正文取得/摘要/媒体/失败。具体失败原因展示在补充框之前；保留原链接和打开原作品入口；补充资料后跳过已失败的再次读取。无文字则不发分析请求。
