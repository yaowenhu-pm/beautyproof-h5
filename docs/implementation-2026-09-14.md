# 真妍盾更新方案 · 2026-09-14

## 定位与取舍

面向刷到种草内容、准备购买的消费者，核对具体美妆宣传，而不是鉴定实物正品。保留链接、文字、截图、视频入口；不新增包装鉴定、批号解码、投诉代办、全网查重或 AI 图片真伪承诺。

A 竞品调研用于定位假设；B 用户需求用于低门槛、可追溯和不误判的交互要求；C API 与案例用于待核实线索。三者均不作为科学或监管事实直接入库。其用户规模、付费意愿、接口可用性和品牌事件未全部独立核验，不对外当作已验证事实。

## 本轮实现

1. **证据 RAG**：保留无需额外模型的本地检索，增加监管科普与标签条款；显式记录证据类型、地域、日期、可支持的判断和局限。按宣称分段召回，优先覆盖不同问题，最多四条证据。绝不以案例预期答案作为检索资料。
2. **结论校验**：先检查原文对应与语境，再检查引用存在且与判断类型有关。仅“天然、神器、同款”、未附研究、普通保湿不直接判假。通用原料资料不能证明具体产品有效；不推断实物假货或非法添加。未通过校验时提示不能完成，不伪造成功。
3. **报告**：首屏一句结论、最多三条不重复发现、关键成分、分析范围；展开证据和原文。减少重复解释，保留打印。明确用户补充内容与原链接不一定一致。
4. **服务与费用**：公开只读服务状态，提前告知暂停或额度不足。保留原 D1 累计 1 元 / 测试 0.6 元上限，不重置历史用量；一次生成，无付费重试。2026-09-14 官方中文价目为 Flash 高峰输入 2 元/百万、输出 8 元/百万；按高峰未命中缓存保守扣账。旧 V4 名称实际已由 V4.1 Flash 服务，改用官方名称 deepseek-flash。价格核阅有效期七天，过期停止新调用。
5. **验收材料**：建立独立的 12 条校准用例（明确人工构造与公开样本的区别），另保留真实链接读取清单；记录期望、证据、禁止结论、实际结果及未完成项。免费回归不算模型准确率测试。本轮付费冒烟最多三次、最多 0.10 元，且包含在既有上限内。
6. **交付**：更新 README、来源说明、案例清单、演示脚本；发布原站点并同步原 GitHub。私有团队文档和完整 UGC 不上传公开仓库。

## 验收门槛

- 不同内容与引用各自对应，不复用其他作品的报告。
- 正常、辟谣、缺证据样本不得被自动输出为假货。
- 成分只展示实际识别项及来源，不补配方、不生成安全分。
- 网络失败、模型失败、预算不足、价格失效可区分；不自动重试扣款。
- 免费结构/预算测试与真实模型测试分开记录；有限测试不宣称大规模准确率。
