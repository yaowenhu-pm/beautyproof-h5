## 已修复

1. 页面初始状态中的 `new Map([])`、`undefined` 占位符使 JSON 解析失败。仅安全替换字符串之外的空占位，不执行页面脚本，不接受任意 JavaScript。
2. 多次状态赋值时选取当前状态；支持通过显式作品 ID 匹配不透明 map 键。冲突、缺失或多义身份一律失败，不拿推荐作品补结果。
3. 遇到 `/404`、登录/验证路由、无作品 ID 的信息流/主页跳转立即停止；明确可见门禁优先于内嵌陈旧正文。
4. 原先 `metadata_only / media_only` 因 `resolved=true` 被缓存 5 分钟。现在前端、服务端、队列和直连接口统一：只有 `ok + body + full + 非空正文` 缓存 5 分钟；部分结果和失败缓存最多 10 秒。
5. 网站 TS 与云端生成件不同步。新增 `node scripts/build-reader.mjs`，用相同源码重建云端模块，并以同组离线输入验证结果一致。
6. Linux 发布错误：移除显式必装的 Windows 原生构建依赖；平台绑定由构建器的可选依赖选择。

请求完整分享参数保留，不改为去参数链接。没有复制个人 Cookie、扩大网络权限、关闭 TLS、绕过验证码或新增付费服务。
