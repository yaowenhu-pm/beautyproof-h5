## 本版流程

### 云端读取接入（开发分支，尚未切换生产）

已实现 Sites 主动调用 ECS 的签名 HTTPS 接口：专用 Ed25519 密钥、请求关联、重放保护、限流、有限队列、独立匿名浏览器沙箱、超时取消与作品身份检查。代码及安装文件见 `ops/cloud-reader/`；完整方案见 [云端接入方案](docs/cloud-reader-solution-2026-09-20.md)。模型预算及付费开关不变，此轮读取测试不调用模型。

当前杭州 ECS 的临时域名被阿里云以 `Non-compliance ICP Filing` 拦截，免费证书验证收到 403。**不能把代码完成或 ECS 内部测试等同于现有网站已接通。** 正式网站继续使用上一版读取路径，待提供符合接入要求的已备案域名后再完成公网 HTTPS 与网站端到端验收，不绕过拦截、不关闭证书校验。

固定验收集为小红书 10 条、抖音 10 条，包括历史失败样本；`acceptance-20.mjs` 逐条测试、无自动重试，非空正文和作品身份均通过才计成功。仅标题、验证码、App 提示、搜索摘要均不算通过。测试报告保留失败，不能通过更换样本凑齐 20/20。

**2026-09-20 ECS 内部四轮实测：0/20 → 6/20 → 6/20 → 6/20。** 已修复短链别名误判、浏览器超时阻塞后续请求、清理耗时覆盖真实结果及正常导航时的读取竞态。最终小红书 6 条取得正文、4 条 App 限制；抖音 10 条均从原作品跳转到精选页，未取得原作品正文。没有达到 20/20，也没有完成公开网站端到端验收。域名/证书与平台内容访问是两个独立阻断，前者解决不代表后者解决。逐项耗时、失败历史和工程测试见 [固定 20 条验收记录](docs/cloud-reader-20-acceptance-2026-09-20.md)。

### 专用账号测试准备（未登录、未上线）

按“暂无专用账号，先准备测试”的决定，新增仅内存、分平台、短时可撤销的实验会话，以及固定原 20 条的内部验收程序。`node ops/cloud-reader/authorized-acceptance.mjs --preflight` 只做离线检查，不读取个人浏览器、不登录、不发平台请求；默认服务仍为匿名。当前尚未实现私有云端扫码登录界面，不能把准备完成说成授权读取已跑通。

官方接口核查也有边界：抖音视频接口主要针对授权账号自己的作品；小红书公开账号授权文档的 `read_notes` 仍标为规划中。专用账号网页登录只是访问能力实验，不代表平台授权其为所有访客读取任意作者内容。实现范围、官方来源、测试与后续条件见 [授权读取准备记录](docs/authorized-reader-preparation-2026-09-20.md)。

### 分析流程

链接 / 文字 / 图片 / 视频 → 提取文字 → 按宣称检索最多4段证据 → DeepSeek Flash → 引文、语境与来源校验 → 简洁报告。

本次更新方案与边界：[2026-09-14 实施方案](docs/implementation-2026-09-14.md)。模型服务目前为 DeepSeek V4.1 Flash，官方原 V4 Flash 别名也已指向新版本。

- 支持小红书、抖音分享文本、短链及常见作品链接，保留签名参数，限制跳转域名。
- 识别标题/摘要、正文、媒体的差异。平台拒绝读取时保留链接，并提供补充文字、截图、原视频入口。不保证所有平台链接可读，不绕过登录/验证码或风控。
- 图片在浏览器执行中英文OCR；视频保留抽帧OCR与最多前24秒Whisper转写。初次模型下载较慢、弱设备或网络可能失败。基于文字快速分析时明确不覆盖全部视频。
- 服务端一次V4 Flash生成，关闭思考，无付费自动重试、无Pro升级。无需本地大语言模型或向量模型，无需用户电脑充当网站服务器。
- 8段带类型、地域、章节、版本和局限的人工整理知识摘要，按宣称分段召回并优先覆盖不同问题，最多4条；保留30个常见INCI映射。新增睫毛生长监管科普、全成分标签、量化指标与原料功效关联条款。当前没有向量检索和飞书全量入库。
- 报告首屏给具体结论，最多3项发现；可展开原文、理由、法规/资料链接，列出识别成分与分析范围，浏览器打印/保存PDF。
- 成分区分“内容提及”和“用户标记的标签截图”。只有匹配到的成分才展示；不根据产品名猜配方，不显示未经验证的安全评分。
- 引文必须是输入中的连续原文，引用id必须来自本次检索资料。风险判断必须含引用。本版无产品级功效资料，不输出“功效已获支持”；正常表述标记为语境说明，不当作功效认证。不保证自动验证语义蕴含完全正确，仍需人工抽查。
- 旧报告展示分支和旧规则代码保留；旧规则不再决定V2最终结论。V2未开放全网查重，旧指纹信息不参与真假定性。
- 相同输入、范围、资料版本与模型配置复用缓存。标题或URL不同不会错误复用另一条报告。
- 模型不可用或校验失败明确显示“未完成判断”，保留已提取内容及参考资料。

## 一元演示预算

本轮项目API总支出上限人民币1元，其中真实测试最多0.6元；不是每人1元，也不是每天自动重置。

生产D1中的 `api_calls` 表用单条原子SQL按预算条件插入预留，同时用主键防止相同输入并发扣费。输入按UTF-8字节数加协议余量保守估计，输出最多1200 tokens，均按高峰未命中价格预留。收到usage后按峰值输入/输出价记账；实际账单可能更低。网络超时或usage缺失时不释放预留，不自动重试。

官方价格核阅于2026-09-14：[DeepSeek价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。Flash高峰输入2元、输出8元/百万tokens；闲时更低。价格审核有效期至北京时间2026-09-21 00:00，过期暂停新的付费调用，需人工重新核价，不自动提高或重置预算。历史记账保留原值，不按新价格回写。

公开只读 `GET /api/status` 提供服务就绪、未配置、价格失效、额度不足、存储不可用状态，不公开密钥或用户内容。输入页提前提示不可用状态，仍允许尝试获取同版本相同内容的已有缓存。状态查询不是额度预留，实际调用以原子预算检查为准。

测试与公开网站共享一个生产账本；不要另建带真实密钥的本地账本，否则不能保证跨环境1元总上限。管理员 `GET /api/budget` 需私密 `x-beautyproof-test` 请求头，返回费用与调用汇总，不公开用户内容。测试请求带同一凭证才计入test分组。

## 本地开发

需要Node.js 22.13+。使用已有package-lock安装：

```sh
npm ci
npm run dev -- --port 3010
npm run test:v2
npm run test:links
npm run test:rules
npx tsc --noEmit
npm run build
```

首次本地D1需要应用生成迁移。完成build后可执行：

```sh
npx wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_solid_morph.sql
npx wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_bored_boom_boom.sql
```

以上首次初始化命令不要对已应用的迁移重复执行。生产由Sites部署流程管理Drizzle迁移，不在请求处理时建表。

本地默认不启用付费生成：仍可检查页面、OCR、链接解析和失败提示。配置名见 `.env.example`。生产密钥用Sites运行时secret配置，不放网页、Git、URL或README。生产开关 `BEAUTYPROOF_PAID_ENABLED=true`，模型固定为 `deepseek-flash`，官方地址固定为 `https://api.deepseek.com/chat/completions`。

## 代码组织

`app/page.tsx` 输入流程；`app/report-v2.tsx` 简洁报告；`app/api/resolve` 平台读取；`lib/server/analysis-v2.ts` 检索与V4分析；`lib/shared/report.ts` 校验；`lib/shared/knowledge.ts` 资料和成分；`lib/shared/budget.ts` 费用策略；`db/schema.ts` 与 `drizzle/` 持久化；`lib/client/extraction.ts` 浏览器OCR/ASR。

生产沿用Sites Cloudflare Workers + D1，不需要本机常驻服务。GitHub用于保存源码，GitHub Pages本身不能运行本项目的服务端检测API。
