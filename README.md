# 真妍盾 BeautyProof

面向欧莱雅黑客松赛道二的美妆内容鉴真 H5 MVP。支持小红书/抖音链接、文字、图片与视频输入，并执行内容抽取、内容指纹、库内查重、C2PA/EXIF 读取和宣称证据核验。

## 当前已实现

- 服务端解析小红书/抖音公开链接、跳转地址和作品 ID；小红书可读页面会继续提取正文和公开媒体，平台阻止读取时返回明确的受限状态。
- 图片：浏览器端 Tesseract.js 中英文 OCR、SHA-256、64 位感知指纹、尺寸、EXIF 和 C2PA 内容凭证。
- 视频：最多五个画面 OCR、Whisper 自动语言口播转写（最多前 60 秒）、重复/退化文本质量拒绝、SHA-256、关键帧感知指纹、分辨率、时长和 C2PA 内容凭证。
- 文字：64 位 SimHash、时限/量化/绝对化/医疗化等宣称规则，并映射 NMPA、SAMR、FDA 官方资料。
- D1 内容指纹库：检测完全一致、图片近似、视频关键帧近似和文字近似记录。

## 能力边界

查重范围是本系统已经检测的内容，不是全网内容；当前没有接入深度伪造或 AI 生成分类模型。抖音网页可能因平台访问策略只能识别作品，此时需要用户上传原视频才能执行 OCR、ASR 与关键帧分析。缺少 C2PA/EXIF、没有查重命中或未命中规则，都不能作为内容真实的证明。

OCR 与 ASR 在浏览器本机运行，首次使用会下载对应模型，耗时取决于网络和设备能力；原始上传文件不会发送到分析后端，后端只保存抽取文本、指纹和报告结果。

报告默认只展示结论、三条关键发现和下一步建议。SHA-256、感知指纹、OCR/ASR 明细与官方引用收在“技术详情”中；其中内容指纹只用于判断文件是否相同或近似，不是风险分数。
