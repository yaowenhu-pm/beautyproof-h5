# 真妍盾 BeautyProof

面向欧莱雅黑客松赛道二的美妆内容鉴真 H5 MVP。支持小红书/抖音链接、文字、图片与视频输入，并执行真实的平台解析、内容指纹、库内查重、C2PA/EXIF 读取和宣称规则核验。

## 当前已实现

- 服务端解析小红书/抖音公开链接、跳转地址和作品 ID；平台风控阻止读取时返回明确的受限状态。
- 图片：SHA-256、64 位感知指纹、尺寸、EXIF 和 C2PA 内容凭证。
- 视频：SHA-256、三个关键帧感知指纹、分辨率、时长和 C2PA 内容凭证。
- 文字：64 位 SimHash，以及时限、量化、绝对化、医疗化等宣称规则。
- D1 内容指纹库：检测完全一致、图片近似、视频关键帧近似和文字近似记录。

## 能力边界

查重范围是本系统已经检测的内容，不是全网内容；当前没有接入深度伪造或 AI 生成分类模型。缺少 C2PA/EXIF 或没有查重命中，都不能作为内容真实的证明。
